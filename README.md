## 📄 Sobre o Projeto

Este repositório contém o código-fonte da landing page oficial da **Pé Quente 013**, uma loja especializada em sneakers premium localizada em São Vicente/SP. 

O foco principal deste desenvolvimento não foi apenas criar uma vitrine digital, mas sim uma ferramenta estratégica para **aumentar o tráfego orgânico** e converter visitantes em clientes via WhatsApp, otimizando a presença digital da marca na Baixada Santista.

---

## 🎯 Objetivos Estratégicos

Para atender às necessidades da loja, o projeto foi construído focando em três pilares:

1.  **Performance & Velocidade:** Carregamento rápido para garantir que o cliente não desista da compra (essencial para tráfego pago e orgânico).
2.  **SEO Local:** Otimização para mecanismos de busca com foco em palavras-chave da região (São Vicente, 013, Sneakers).
3.  **Conversão Direta:** Botões estratégicos de "Comprar Agora" e "Contato" integrados diretamente ao WhatsApp da loja.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as melhores práticas de desenvolvimento web moderno:

* **HTML5 Semântico:** Para melhor indexação nos motores de busca (Google).
* **CSS3 Customizado:** Design responsivo que se adapta a qualquer tela (Mobile First).
* **Integração com API do WhatsApp:** Facilitando a jornada de compra do cliente.
* **Google Maps Integration:** Para facilitar a localização da loja física no Centro de São Vicente.

---

## ✨ Funcionalidades Principais

* ✅ **Vitrine de Marcas:** Exibição das principais marcas (Nike, Adidas, Puma, Mizuno, etc).
* ✅ **Destaque de Produto:** Seção detalhada para modelos ícones (ex: Puma Suede).
* ✅ **Tabela Comparativa:** Demonstração visual do custo-benefício da loja vs concorrência.
* ✅ **Seção Sobre Nós:** Contando a história da marca e sua ligação com a cultura urbana de São Vicente.
* ✅ **Rodapé Informativo:** Links de suporte, guias de tamanhos e FAQ.

---

## 📈 Resultados para o Negócio

Ao utilizar este repositório, a loja **Pé Quente 013** passa a ter:
- Maior autoridade digital no nicho de calçados.
- Uma página otimizada para campanhas de tráfego (Instagram Ads/Facebook Ads).
- Centralização de informações, reduzindo o tempo de atendimento manual.
